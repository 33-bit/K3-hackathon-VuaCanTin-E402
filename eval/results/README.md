# Kết quả đánh giá

Thư mục này nhận kết quả do `eval/run_eval.py` tạo ra.

Sau lần chạy chính thức, cần commit:

- `run-<timestamp>.jsonl`
- `run-<timestamp>.csv`
- `summary-<timestamp>.md`
- `latest.csv`
- `latest-summary.md`

Không xóa các dòng fail và không thay đổi quality bar sau khi đã xem kết quả lần đầu.
